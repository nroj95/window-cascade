# Window Cascade

an experimental AutoHotkey v2 window manager that automatically arranges desktop windows into cascading layouts.

supports multiple monitors, window stacks, keyboard navigation, drag-and-drop placement, and clickable focus tabs.

**status:** experimental. functionality and keybindings may change.

## usage

run `window-cascade.ahk`.

this initial version requires the legacy `capslock-layer.ahk` script to be running for keyboard commands. integration with the newer Caps + Pause Layers service is planned.

see [documentation](window-cascade/README.md) for controls and settings.
